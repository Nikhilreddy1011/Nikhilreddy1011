### Selected Work

**TailorAI** — AI resume-to-job matching assistant
<br><samp>React.js · FastAPI · LangChain · MongoDB</samp>
<br>Most resume tools do one-shot LLM calls and hope for structured output. This runs a 4-step LangChain pipeline — parse resume → analyze job description → detect skill gaps → generate a tailored cover letter — so each step is debuggable independently instead of one prompt trying to do everything at once.

<br>

**QuizGen** — real-time AI quiz generator
<br><samp>React.js · FastAPI · LangChain · JWT · MongoDB</samp>
<br>Built during the Infosys Springboard internship. Generates structured quizzes on demand from any topic via LLM, with JWT-secured sessions and REST APIs validated through Postman before shipping.

<br>

**GITAM Academic Tracker** — full-stack student dashboard
<br><samp>React.js · Node.js · Express.js · MongoDB · JWT</samp>
<br>Attendance, SGPA calculation, task management, and study planning in one place, replacing scattered spreadsheets. RESTful API layer with JWT-scoped access per user, deployed live on Render.

<br>

**Code Debugger / Code Generator** — MCP server
<br><samp>Model Context Protocol · Python</samp>
<br>Exposes debugging and code-generation as callable tools over MCP — built to explore agentic tool-use patterns beyond single-shot prompting, the same protocol powering modern AI coding assistants.
