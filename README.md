## Projects

### 🤖 TailorAI — AI-Powered Job Application Assistant
**React.js · FastAPI · LangChain · MongoDB**

Analyzes a resume against a job description and generates ATS keyword suggestions, a skill gap report, and a personalized cover letter. Built as a multi-step LangChain workflow — resume parsing → JD analysis → gap detection → cover letter generation — rather than a single prompt call.

[GitHub →](https://github.com/Nikhilreddy1011)

---

### 📝 QuizGen — AI-Powered Quiz Generator
**React.js · FastAPI · LangChain · JWT · MongoDB**

Built during the Infosys Springboard internship — generates structured quizzes dynamically from a topic using an LLM, with JWT-based auth and REST APIs tested via Postman.

[GitHub →](https://github.com/Nikhilreddy1011)

---

### 🎓 GITAM Academic Tracker
**React.js · Node.js · Express.js · MongoDB · JWT**

A full-stack academic management platform — attendance, SGPA tracking, task management, and study planning in one dashboard. RESTful APIs with JWT auth, deployed on Render.

[GitHub →](https://github.com/Nikhilreddy1011)

---

### 🛠️ Code Debugger / Code Generator — MCP Server
**MCP · Python**

An MCP (Model Context Protocol) server exposing code debugging and code generation as callable tools — built to explore agentic tool-use patterns beyond single-shot LLM prompting.

[GitHub →](https://github.com/Nikhilreddy1011)
